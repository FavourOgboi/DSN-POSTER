# Machine Learning-Driven Corrosion Inhibition Study: Okro Leaf Extract in Acidic and Basic Media

## Overview
This comprehensive study investigates the corrosion inhibition performance of Okro leaf extract (Abelmoschus esculentus) in both acidic (HCl) and basic (NaOH) media using advanced electrochemical techniques and machine learning approaches. The research employs Tafel polarization as the primary electrochemical method, with enhanced models incorporating Open Circuit Potential (OCP) and Linear Sweep Voltammetry (LSV) features for improved prediction accuracy.

## Dataset Characteristics
- **Media**: HCl (1.0-2.5 M) and NaOH (1.0-2.5 M)
- **Inhibitor**: Okro leaf extract (50-200 ppm)
- **Temperature**: 30-60°C
- **Samples**: 17 experimental conditions per medium
- **Target Variable**: Corrosion rate (CR_mm_yr)
- **Electrochemical Parameters**: E_corr_V, j_corr_A_cm2, PR_ohm, OCP features, LSV features

## EXPERIMENTAL INSIGHTS COMPARISON

### Corrosion Rate Trends

#### Acidic Media (HCl)
- **HCl Concentration**: Weak positive correlation (r = 0.069), corrosion increases from 1.0M to 2.5M
- **Inhibitor Concentration**: Moderate negative correlation (r = -0.350), non-linear with irregularity at 125 ppm
- **Temperature**: Weak positive correlation (r = 0.336), corrosion accelerates above 45°C
- **Range**: 35-125 mm/yr, mean ~84 mm/yr
- **Optimal**: 125 ppm inhibitor, 30°C, 2.5M HCl (CR = 35 mm/yr)

#### Basic Media (NaOH)
- **NaOH Concentration**: Strong positive correlation (r = 0.447), sharp increase from 1.0M to 2.5M (+920%)
- **Inhibitor Concentration**: Negative correlation (r = -0.350), non-linear with spike at 125 ppm
- **Temperature**: Dominant factor (r = 0.577), strongest influence on corrosion
- **Range**: 35-221 mm/yr, wider variation due to aggressive high NaOH
- **Optimal**: 125 ppm inhibitor, 30°C, 1.0M NaOH (CR = ~35 mm/yr)

#### Key Comparison
- **Media Aggressiveness**: Basic media shows more extreme corrosion rates at high concentrations
- **Inhibitor Response**: Acidic shows more predictable linear response; basic has complex non-linear behavior
- **Temperature Impact**: Both show acceleration, but basic media more sensitive to temperature-inhibitor interactions
- **Concentration Effects**: Base concentration dominates in basic media; acid concentration secondary in acidic media

### Inhibitor Performance Analysis

#### Acidic Media Inhibitor Effectiveness
- **50 ppm**: Strong inhibition, stable performance at low concentrations
- **125 ppm**: Irregular behavior, possible film instability/disruption
- **200 ppm**: Moderate recovery, most effective at higher doses
- **Temperature Sensitivity**: Performance decreases above 45°C, especially at 125-200 ppm

#### Basic Media Inhibitor Effectiveness
- **50 ppm**: Most effective, minimal corrosion rates, optimal stability
- **125 ppm**: Poor inhibition, corrosion rate increases significantly (film disruption)
- **200 ppm**: Moderate recovery, better at higher temperatures
- **Temperature Sensitivity**: Strongest at 200 ppm, performance drops sharply with temperature

#### Comparative Inhibitor Analysis
- **Optimal Concentrations**: Acidic (125-200 ppm); Basic (50-125 ppm)
- **Stability**: Acidic shows more consistent response; basic has instability at mid-range doses
- **Temperature Interaction**: Both decrease effectiveness with heat, but basic more sensitive
- **Mechanism**: Mixed-type inhibition in both, but different adsorption patterns

### Electrochemical Correlations

#### Acidic Media
- **Strongest Predictor**: Current density (j_corr) with r = 0.899 to CR
- **Polarization Resistance**: Strong inverse correlation (r = -0.658)
- **Corrosion Potential**: Weak negative correlation (r = 0.307)
- **HCl Impact**: Minimal direct correlation (r = 0.069)

#### Basic Media
- **Strongest Predictor**: Temperature (r = 0.577 to CR)
- **Secondary Predictors**: Inhibitor (r = -0.350), NaOH concentration (r = 0.447)
- **Polarization Resistance**: Moderate inverse correlation with CR
- **Corrosion Potential**: Indicates mixed-type inhibition mechanism

#### Electrochemical Comparison
- **Dominant Factors**: Current density (acidic) vs temperature (basic)
- **PR-CR Relationship**: Stronger correlation in acidic media
- **Inhibition Type**: Mixed-type in both media
- **Data Variability**: Acidic shows more variable electrochemical responses

## FEATURE ENGINEERING COMPARISON

### Tafel-Only Features (15 total)
**Base Features**: HCl_M/NaOH_M, Inhibitor_ppm, Temp_C
**Engineered Features**:
- Polynomial: Concentration², Inhibitor², Temperature²
- Logarithmic: Log(Concentration), Log(Inhibitor), Log(Temperature)
- Inverse: 1/Concentration, 1/Inhibitor, 1/Temperature
- Interactions: Conc×Inhibitor, Conc×Temp, Inhibitor×Temp

### Enhanced Features (22 total)
**Tafel Features**: All 15 above
**OCP Features**: Initial potential, Final potential, Potential range, Potential std
**LSV Features**: Anodic slope, Cathodic slope, Peak current

### Feature Importance Insights

#### Acidic Media (XGBoost)
- HCl_sq (43.5%): Non-linear acid concentration effects
- HCl_Temp (19.5%): Acid-temperature interactions
- Temp_C (8.6%): Direct temperature influence
- Inhibitor_ppm (7.0%): Inhibitor concentration effects

#### Basic Media (Random Forest)
- Temperature (dominant): Primary corrosion driver
- Inhibitor concentration: Secondary effect
- NaOH concentration: Base strength influence
- Interaction terms: Complex relationships

## ENGINEERING RECOMMENDATIONS

### Acidic Media (HCl) Guidelines
- **Optimal Dosing**: 125-200 ppm inhibitor
- **Temperature Control**: Maintain <45°C
- **Acid Limits**: HCl ≤1.75M for effective inhibition
- **Monitoring**: Track E_corr and PR for performance assessment
- **Critical Conditions**: Increase inhibitor dose for HCl >2M

### Basic Media (NaOH) Guidelines
- **Optimal Dosing**: 50-125 ppm inhibitor (lower than acidic)
- **Temperature Control**: Critical, maintain <45°C
- **Base Limits**: NaOH ≤1.75M to prevent extreme corrosion
- **Monitoring**: Regular CR assessment required
- **Critical Conditions**: Avoid NaOH >2M, monitor closely at high temperatures

### Comparative Operational Strategy
- **Media Selection**: Prefer basic media for lower baseline corrosion
- **Inhibitor Optimization**: Acidic requires higher doses; basic more sensitive to concentration
- **Temperature Management**: Essential in both, but basic more temperature-critical
- **Monitoring Frequency**: Higher in basic media due to wider corrosion range

## LIMITATIONS & FUTURE WORK

### Current Study Limitations
- Small datasets (17 samples each) limit statistical power
- Laboratory-scale experiments, no field validation
- Single acid/base systems (HCl/NaOH only)
- Missing OCP/LSV data for some conditions
- Complex non-linear relationships not fully captured

4. **Mechanistic Studies**: Adsorption isotherms, surface analysis (SEM, XPS)

6. **Synergistic Effects**: Combination with conventional inhibitors
7. **Long-term Testing**: Dynamic conditions, cyclic exposure studies

### Inhibitor Effectiveness
- **Okro Leaf Extract**: Proven effective in both media as eco-friendly corrosion inhibitor
- **Performance**: Comparable to conventional inhibitors with environmental advantages

### Modeling Insights
- **Enhanced Features**: OCP and LSV data significantly improve prediction accuracy

- **Generalization**: Enhanced models show better stability and predictive power

### Key Takeaways

4. **Practical Value**: ML-driven approach enables data-driven corrosion management strategies

This comprehensive study demonstrates that machine learning combined with extensive electrochemical characterization provides superior corrosion prediction and control strategies, with significant implications for industrial corrosion management using sustainable inhibitors.
